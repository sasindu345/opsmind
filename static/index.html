Connect Developer Tools & Webhooks

Seamlessly integrate your GitHub repositories, Prometheus, and CloudWatch alerts with OpsMind.

GitHub Repository Webhook

Auto-correlate git commits and deploy onsets to outages.

1 Open your GitHub repository ➔ Settings ➔ Webhooks ➔ Add Webhook
2 Paste Payload URL:
http://localhost:8000/api/v1/webhooks/github
3 Select Content Type: application/json and events: Pushes & Deployments.

Prometheus Alertmanager

Stream threshold breaches & metric anomalies directly.

1 Add webhook receiver in your alertmanager.yml: 
receivers:
  - name: 'opsmind-webhook'
    webhook_configs:
      - url: 'http://opsmind:8000/api/v1/webhooks/prometheus'
        send_resolved: true

Guarded Remediation Runbooks

Allowlist-only execution engine with strict parameter validation, dry-run previews, and immutable audit logs.

MEDIUM RISK

Rollback Deployment

Rolls back a Kubernetes deployment to its previous stable revision.

kubectl rollout undo deployment/{service} -n {namespace}
LOW RISK

Graceful Service Restart

Initiates a rolling restart of all pods in the target service deployment.

kubectl rollout restart deployment/{service} -n {namespace}
MEDIUM RISK

Scale Workload Replicas

Adjusts replica count (1 to 20) to relieve CPU or memory saturation.

kubectl scale deployment/{service} --replicas={replicas}
HIGH RISK

Async Cache Flush

Flushes transient Redis cache keyspace asynchronously to clear bad cache keys.

redis-cli -h {host} -p {port} FLUSHDB ASYNC
